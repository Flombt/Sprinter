# Décisions durables

[Carte documentaire](../00-INDEX.md)

Ces décisions décrivent les choix en vigueur observés dans le code le 15 novembre 2026. Leur justification reprend les intentions historiques lorsqu’elles sont cohérentes avec ce code ; les conséquences sont une synthèse technique. Elles ne valent pas validation d’exploitation.

| Décision | À lire avant de modifier |
|---|---|
| [001 · Calcul local et persistance](001-calcul-local-et-persistance.md) | GPS, horloges, stockage, récupération, calculs fiables |
| [002 · Compte obligatoire, cloud facultatif](002-compte-obligatoire-et-cloud-facultatif.md) | Démarrage, connexion, déconnexion, consentements |
| [003 · Expo, variantes et compilation iOS](003-expo-et-variantes-ios.md) | Dépendances natives, plateforme, Santé, Live Activity, IPA |
| [004 · Confidentialité et publication](004-confidentialite-et-publication.md) | Partage, exports, médias, profil public, thèmes |
| [005 · Synchronisation et autorité serveur](005-synchronisation-et-autorite-serveur.md) | Outbox, conflits, comptes multiples, RLS, admin |
| [006 · UI et état de session](006-interface-et-etat.md) | Navigation, abonnements, composants et accessibilité |

Un changement volontaire peut remplacer une décision : documenter le motif, le nouveau comportement et les conséquences, puis mettre à jour les seules fiches concernées. Ne pas traiter un ancien cahier des charges comme une décision actuelle ; les attentes devenues incompatibles sont dans les [archives](../archive/README.md).
